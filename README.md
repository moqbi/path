# آثار مومنتس · ATHAR Moments

«لحظاتك، مع ناسك.»

شبكةٌ اجتماعيّة حميمة بدائرةٍ لا تتجاوز ١٥٠ صديقاً: لحظاتٌ (صورة، مكان،
أغنية، خاطرة، نوم وصحو)، وقصصٌ ليوم، ونوت فوق الصورة، ومحادثات، ومتجرٌ
للإطارات والتشارمز والثيمات ومجموعاتِ الملصقات، وتقويمُ مناسباتك، وكتابُ سنتك —
بلا استكشافٍ عامّ ولا غرباء.

**منشورٌ على App Store** (الإصدار ٠٫١٫٢)، وموقعُه وتطبيقُ الويب على
[atharmts.com](https://atharmts.com).

## أين كلُّ شيء

| المجلّد | ما هو | أين يعمل |
|---|---|---|
| `apps/mobile` | التطبيق — Expo + React Native | App Store، وتحديثاتُ OTA |
| `apps/api` | الواجهة البرمجيّة — Hono، يكلّمها الجوّال على `/v1/*` | الخادم، منفذ ٤٠٠٠ |
| `apps/web` | الموقع العامّ (الهبوط والقانونيّ و`/u/*`) واللوحة `/admin` | الخادم، منفذ ٣٠٠١، على الجذر |
| `src/` (الجذر) | تطبيقُ الويب — Next.js بـ`basePath` `/app` | الخادم، منفذ ٣٠٠٠، تحت `/app` |
| `packages/shared` | ثوابتُ ومخطّطات Zod مشتركة | — |
| `packages/db` · `prisma/` | عميلُ Prisma والمخطّطُ والهجرات | Postgres 16 على الخادم |
| `packages/storage` | الملفّات في Cloudflare R2 (توقيع SigV4 بأيدينا) | — |

## القرارات التي يقوم عليها المنتج

مختصرُها، والتفصيلُ في `CLAUDE.md`:

- **سقف الدائرة ١٥٠ ولا يُباع.** ما يُباع يدور حول الذاكرة والتعبير — لا حول توسيع الدائرة.
- **لا استكشاف عامّ.** اللحظة لصاحبها ولدائرته وحدها.
- **التفاعلاتُ الأساسيّة مفتوحةٌ للجميع.** الإيموجي الحرّ وحده لآثار+.
- **لا يُدخل يدويّاً ما يعرفه الجهاز.** المكانُ من الموقع، والأغنيةُ من حسابٍ مربوط.
- **لا صناديق عشوائيّة في المتجر.** بيعٌ مباشر بسعرٍ واضح، والنقاطُ تُشترى من متجر المنصّة وحده.

## التشغيل محلّيّاً

```bash
pnpm install
cp .env.example .env          # DATABASE_URL و AUTH_SECRET على الأقلّ
npx prisma migrate deploy
npm run db:seed
npm run dev                   # تطبيق الويب على /app
pnpm --filter @athar/web dev  # الموقع واللوحة على ٣٠٠١
```

حساباتُ التجربة بعد البذرة كلُّها بكلمة المرور `athar1234` على
`@athar.test`: `mohammed@` · `noura@` (مشتركة) · `naif@` · `sultan@`.

وقبل أيّ تسليم: `npm run typecheck` و`npx next build`، ثمّ **جرّب المسار
فعلاً في متصفّح** — البناءُ الناجح ليس دليلاً على أنّ الشاشة تعمل.
