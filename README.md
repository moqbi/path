# آثار مومنتس · ATHAR Moments

«لحظاتك، مع ناسك.»

شبكة اجتماعية حميمية بدائرة محدودة: خط زمني للحظات، حضور مؤقت مع دعوة، وأرشيف شخصي يتراكم لصاحبه حتى لو صمت الجميع.

نموذج أولي على الويب. المنتج النهائي تطبيق جوال (React Native/Expo) على نفس الخلفية والمخطط.

## القرارات التي يقوم عليها المنتج

- **سقف الدائرة ١٥٠ ولا يُشترى.** كل ما يُباع في «آثار+» يدور حول الذاكرة والتعبير والتحكم — لا حول توسيع الدائرة. بيع خانات أصدقاء يبيع تدمير المنتج نفسه.
- **الحضور المؤقت هو التمايز.** منشور له وقت انتهاء وزر «جاي»، لا تسجيل حضور ميت. هذا يحوّل الـcheck-in من إعلان إلى دعوة قابلة للتنفيذ.
- **الإشارة «مع فلان» بموافقة الطرف الآخر.** إعلان وجود شخص في مكان قد يورّطه.
- **لا استكشاف عام.** اللحظة لصاحبها ولدائرته فقط. تبويب «اكتشف» هو ما قتل Path الأصلي.
- **التفاعلات الخمسة مفتوحة للجميع دائماً.** الإيموجي الحر وحده وراء الاشتراك — حصر التفاعل الأساسي يقلّل حجم التفاعل الكلي ويضرب الاحتفاظ.
- **لا صناديق عشوائية في المتجر.** بيع مباشر بسعر واضح.

## التشغيل

```bash
npm install
cp .env.example .env          # املأ DATABASE_URL و AUTH_SECRET
npx prisma migrate deploy
npm run db:seed
npm run dev
```

## ما هو مؤقت في هذا النموذج

- **الصور تدرّجات CSS** لا ملفات مرفوعة — لتفادي إعداد تخزين في مرحلة التحقق.
- **الاشتراك يُفعَّل بضغطة** بلا دفع. في التطبيق الحقيقي يمر الدفع عبر IAP لآبل و Google Play Billing إلزامياً؛ Apple Pay ومدى ممنوعة للسلع الرقمية.
- **الإيموجي الحر قائمة جاهزة** بدل فتح كيبورد النظام.
- **الحضور المنتهي يُخفى بالاستعلام** لا بمهمة مجدولة. في الإنتاج: `pg_cron`.
- **لا إشعارات** — تحتاج تطبيقاً أصلياً.

## الخطوة التالية

نقل الواجهة إلى React Native/Expo مع إبقاء المخطط والقاعدة كما هما. القاعدة Postgres عادي، فالانتقال إلى خادمك لا يتطلب أكثر من `pg_dump` و`pg_restore`.
