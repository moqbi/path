# ويب آثار الموحّد

صفحاتٌ عامة (الهبوط والقانوني والوظائف وحذف الحساب) ولوحة تحكّم محمية —
تطبيقٌ واحد لا اثنان: دومينٌ واحد، وجلسةٌ واحدة، ونشرٌ واحد.

## الحالة

منشورٌ على `atharmts.com` (الخدمة `athar-site`، منفذ ٣٠٠١) — الجذرُ له،
وتطبيقُ الويب تحت `/app` مشروعٌ آخر في جذر المستودع (القاعدة ١٢٢).
وصفحةُ الهبوط بطاقاتٌ بعرض الشاشة (القاعدة ٢٧٦)، ونصوصُها كلُّها من
اللوحة ← «الموقع» (القاعدة ١١٠).

## المسارات

| المسار | الوصف |
| --- | --- |
| `/` | صفحة الهبوط |
| `/u/[memberNo]` | بطاقةُ المشاركة (القاعدة ٨٧ب) |
| `/beta` | فريق التجربة |
| `/privacy` · `/terms` | القانوني — شرط المتجرين |
| `/careers` · `/about` · `/contact` | التعريف |
| `/delete-account` | حذف الحساب من الويب — شرط آبل وجوجل |
| `/admin/*` | اللوحة (تتحقّق من الجلسة والدور) |

## ما صار الآن

اللوحة منقولةٌ وتعمل: `/login` ثم `/admin`. الأقسام كما هي في الويب
الحالي — الوسوم والحسابات والمتجر والصلاحيات والملفات والدعم — وزِيد
عليها:

- **البلاغات**: كل بلاغ يُقرأ بيد ويُحسم «حُذف» أو «لا مخالفة». والحذف
  يمسح اللحظة أو القصة أو الرسالة ويُبقي صفَّ البلاغ سجلّاً، فتكرار
  المخالفة من حسابٍ واحد يبقى مرئياً.
- **الكلمات الممنوعة**: القائمة التي تُفحص بها اللحظات والتعليقات
  والرسائل (`lib/moderation.ts` في الخادم وفي الويب معاً). «يمنع» يردّ
  الكتابة، وما دونه يُعلَّم للمراجعة.

ولا ثيمَ في التخطيط: الثيم ثوبٌ يلبسه صاحبه ليرى لحظاته به، واللوحة
أداةُ عمل — ألوانها ثابتة حتى يُقرأ ما فيها كما هو في كل حساب.

والصفحات العامة مبنيّة: الهبوط، و«عن آثار»، وسياسة الخصوصية، وشروط
الاستخدام، و«تواصل معنا» (نموذجٌ يُحفظ رسالةَ دعمٍ بلا حساب ويُقرأ في
اللوحة)، والوظائف، و**حذف الحساب** بالبريد وكلمة المرور — حذفٌ حقيقيّ
فوريّ كالذي في التطبيق.

والقانونيّ والتواصلُ وحذفُ الحساب شروطُ نشرٍ في المتجرين لا تحسينات
لاحقة، ولذلك رابطُها في ذيل كل صفحة لا في الرئيسة وحدها.

```bash
pnpm install
cd apps/web && DATABASE_URL=… AUTH_SECRET=… npx next dev -p 3001
```
